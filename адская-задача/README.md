# Адская задача

150 высот (числа до 36 цифр), 93 простых. Собрана из тайного набора множителей (`hell_secret.json`).
Нарочно убрано всё, за что цепляются методы: ни одна высота не делит другую (нет скачков), все полосы разные.

Что известно:
- нижняя граница: ранг таблицы = 60 (логарифм даёт только 8);
- верхняя граница: 93 (по одному множителю на простое);
- тайный набор содержит 60 множителей — значит, ответ ровно 60 (совпадает с рангом). Но его нужно НАЙТИ, не зная тайны.

Кент скачков и суперкент на ней падают: им нужно держать в памяти 2^60 произведений.
Задача: придумать метод, который найдёт 60 множителей.
