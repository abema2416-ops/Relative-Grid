# Программы проверок «Относительной сетки»

Каждая программа проверяет одно утверждение теории. Все случайные наборы не закреплены:
при повторе числа совпадут по смыслу (ни одной ошибки), а не до штуки.

## Главное: правило отрезков (гипотеза В31, раздел 10.7)

| Программа | Что проверяет | Запуск |
|---|---|---|
| `seg3d/segments3d.cpp` | 3D и 2D: полный перебор всех растяжений против правила отрезков | `g++ -O2 -std=c++17 -o seg segments3d.cpp`, затем `./seg X Y Z D` |
| `partial/p16.py`–`p19.py` | то же для 2D на Python (первая версия) | `python3 p18.py 3 6 3` |
| `partial/p3.py`–`p14.py` | все промежуточные версии правила (таблица 10.6) | `python3 p9.py 3 6 3` |
| `partial/chain*.py` | показать самую короткую цепочку для одной фигуры | `python3 chain5.py` |

`./seg X Y Z D`: поле X×Y×Z, цепочки до D действий. Например, `./seg 3 3 3 3` — куб 3×3×3,
цепочки до 3 (меньше минуты). Строка итога: «совпало N; правило не нашло 0; правило обещает меньше 0».
