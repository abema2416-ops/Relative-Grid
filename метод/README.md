# Метод Зафарова — порядок действий для числа множителей R

Запуск: `g++ -O2 -o core_exact ../программы/big/core_exact.cpp && python3 -I metod.py`

1. Разложить высоты на простые; склеить одинаковые полосы.
2. Узнать узор → сразу точная формула: попарно взаимно простые ⇒ R = D; лесенка степеней ⇒ R = ⌈log₂(D+1)⌉.
3. Нижняя граница L = max(ранг таблицы, ⌈log₂(D+1)⌉).
4. Кенты по очереди (счёт, полосы, скачки, НОД); лучший — верхняя граница U. Если U = L — ответ точный.
5. Точный поиск от L вверх (решатель на масках / суперкент по графику) в пределах времени.
6. Если щель осталась — метод деревьев (группы, содержащие носитель зависимости строк).
7. Выдать формулу: каждую высоту как произведение найденных множителей, и проверить каждую.
Результат: либо R = … с доказательством, либо честная вилка L ≤ R ≤ U с лучшим найденным набором.
