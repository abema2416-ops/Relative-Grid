================================================================
ЧАСТЬ 1. ЯДРО: СТРОГОЕ ОБОЗНАЧЕНИЕ
================================================================

Ядро — это пятёрка  𝒦ₙ = (𝒪ₙ, 𝒜, П, λ, ℓ_𝒜)  для каждого n ≥ 1.

1. Пространство и клетки.
   ℤⁿ — решётка. Клетка — точка c ∈ ℤⁿ; она изображает куб Q(c) = c + [0, 1]ⁿ.
   Ось — номер i ∈ {1, …, n}. Направление — s ∈ {+1, −1}.
   c[i ↦ v] — клетка c, у которой i-я координата заменена на v.
   В Lean: Pt n := Fin n → Int; upd c i v.

2. Объекты 𝒪ₙ.
   Объект — пара (O, S): O ⊂ ℤⁿ конечно и непусто (клетки), S — склейки: пары {c, c'} ⊂ O,
   соседние по стороне: ‖c − c'‖₁ = 1 (в ядре; склейки по ребру и вершине, ‖c − c'‖∞ = 1, — надстройка 9.7). Формы считаются с точностью до сдвига на вектор из ℤⁿ.
   В Lean клетки объекта — предикат Obj n := Pt n → Prop (склейки — отдельно, Glue.lean).

3. Действия 𝒜 (ядро; надстройки α*, α°, подъём, тонкие объекты в ядро не входят).
   (α↑) Растяжение с параметрами (Z, i, s, f), Z ⊂ ℤⁿ конечна, f ≥ 2. Параметра ω в ядре нет
        (совпадение → отказ, П3); исход «слияние/подъём» — надстройка 9.6.
        G = O ∩ Z ≠ ∅;  a = min{ s·c_i : c ∈ G };  t(c) = s·c_i − a.
        α↑(O) = (O \ G) ∪ { c[i ↦ s·(a + f·t(c) + j)] : c ∈ G, 0 ≤ j < f }.
   (α↓) Сжатие:  α↓(O) = (O \ G) ∪ { c[i ↦ s·(a + ⌊t(c)/f⌋)] : c ∈ G }.
   (σ)  Уничтожение:  σ_Z(O) = O \ Z.
   (β₊) Склейка: S ↦ S ∪ K, K — непустое множество касающихся несклеенных пар. Клетки не меняются.
   (β₋) Расклейка: S ↦ S \ K', ∅ ≠ K' ⊂ S. Клетки не меняются.
   (γ)  Поиск касаний — ничего не меняет, действием не считается.
   В Lean: stretch, shrink, sigma, Step (с меткой оси), Chain (цепочка).

4. Правила П (в ядре действуют П1–П5).
   П1. Одно действие — одна зона, одна ось, одно направление, один коэффициент.
   П2. Действия выполняются по очереди.
   П3. Растяжение и сжатие допустимы, только если новые клетки не задевают O \ G (в Lean: P3, P3s).
       Для сжатия это тоже нужно: клетка вне зоны может стоять между закреплённой стороной и группой.
   П4. Подъём размерности — отдельное действие (в ядро не входит).
   П5. Склейки при α (размерность склейки = размерность касания n − ‖c − c'‖₁; T — аффинное растяжение):
       растяжение: f клеток образа одной клетки склеены подряд; склейка {c, c'} переходит в склейки
       всех пар {x, x'} образов, у которых Q(x) ∩ Q(x') ∩ T(Q(c) ∩ Q(c')) той же размерности, что Q(c) ∩ Q(c');
       сжатие: {c, c'} → {φ(c), φ(c')}, при слиянии (φ(c) = φ(c')) склейка исчезает.
       Действие недопустимо, если какая-то склейка не сохраняется с той же размерностью.
       Для склеек по стороне это прежнее правило; растяжение не создаёт склеек по ребру и вершине.

5. Потеря λ.
   Для действия φ с фиксированными (Z, i, s, f) и объекта O:
       λ(φ, O) = log₂ |{ O' : O' \ Z = O \ Z,  φ допустимо на O',  φ(O') = φ(O) }|.
   Потеря считается по клеткам (склейки в подсчёт не входят).
   λ(β₊) = λ(β₋) = 0: по клеткам β ничего не меняет; по состоянию (O, S) при известном K прообраз один
   ((O, S \ K) для β₊(K), (O, S ∪ K) для β₋(K)). Потеря цепочки — сумма.

6. Число действий ℓ_𝒜 (клеточная форма и склейки разделены).
   Для набора разрешённых действий 𝒜 ⊂ {α↑, α↓, σ, β₊, β₋}, начало — одна клетка без склеек:
       ℓ_cell,𝒜(O) = наименьшая длина цепочки из 𝒜, после которой клетки равны O (склейки — любые);
       ℓ_𝒜(O, S) = то же, но склейки в конце ровно S;  ∞, если такой цепочки нет.
   ℓ_cell(O) ≤ ℓ(O, S) ≤ ℓ_cell(O) + 2 (Утв. 42). Где ℓ стоит от одного множества клеток, это ℓ_cell. Стоимость склеек — число пар, склеенных β₊; в ℓ не входит,
   нужна только для счёта дыр (Утв. 16).

7. Сдвиг и зоны (1.24).
   Форма — класс [O] = { O + v }. Действие над формой: зона сдвигается вместе с объектом (Z + v), якорь a + s·v_i.
   α_{Z+v}(O + v) = α_Z(O) + v, σ_{Z+v}(O + v) = σ_Z(O) + v — Lean: stretch_shift, shrink_shift, sigma_shift,
   anchor_shift. Поэтому ℓ и λ не зависят от представителя и от начальной клетки.
   Обозначения: ℓ = ℓ_{все} (полное ядро), ℓ_α = ℓ_{α↑} (только растяжения).
   Всегда ℓ ≤ ℓ_α. При разрешённом σ число ℓ(O) конечно для любого O (ℓ ≤ n + 1, Утв. 35).
   ℓ_α(O) конечно для любого O, связного по граням (Утв. 13).

ЧАСТЬ 3. ЧТО НАЙДЕНО ПРИ АУДИТЕ И СТРОГИЕ ДОКАЗАТЕЛЬСТВА
================================================================

В машинно проверенных утверждениях ошибок, нарушающих их формальную доказуемость, не найдено.
Дополнительно обнаружены и исправлены несогласованности между определением объекта, действиями над
склейками и определением длины цепочки (Н1, Н3, Н7–Н10). Утверждения, доказанные только текстом, проверены
вручную; это слабее машинной проверки, и они помечены в таблице части 2 отдельно (ТЕКСТ, LEAN-ч).

Н1. Число действий зависит от набора разрешённых действий. Раньше писалось просто ℓ.
    Исправление: ℓ_𝒜 (часть 1, п. 6). Утв. 19(а) (нижняя оценка) верно для любого набора — доказано
    в Lean для всего ядра сразу. Утв. 35 — про ℓ с σ. Гипотеза В31 — про ℓ_α (только растяжения).

Н2. NP-трудность счёта R (Утв. 24) — при записи высот в двоичной системе. Высоты в сведении — произведения
    различных простых, их величина растёт экспоненциально, но число цифр — многочленно. Это согласуется
    с Утв. 30(г): там время многочленно от величины наибольшей высоты (псевдомногочленно), а не от числа цифр.
    Исправление внесено в формулировку Утв. 24 и в статью.

Н3. Потеря λ считается по клеткам, склейки в подсчёт не входят. Раньше это подразумевалось
    («Утверждения 1–15 о клетках и битах от склеек не зависят»), теперь записано в определении (часть 1, п. 5).

Н4. Переборы в коробке (В31, таблицы 10.6–10.7) — точные, а не приблизительные: если фигура лежит в коробке,
    то и все промежуточные фигуры любой цепочки растяжений, строящей её, лежат в этой коробке
    (Д4, теорема stretch_frame). Поэтому ограничение поиска коробкой не теряет ни одной цепочки.
    Раньше это не было ни сформулировано, ни доказано.

Н5. Нижняя оценка m(O) ≤ ℓ(O) раньше была доказана для α и σ; теперь машинно для всего ядра (α↑, α↓, σ, β)
    и для любых зон, любых закреплённых сторон и любой длины цепочки.

Н7. Склейки ядра заданы по норме L₁ (соседи по стороне), а не L∞: все утверждения ядра и все программы
    используют только склейки по стороне. Склейки по ребру и вершине — надстройка 9.7 (версия 1.13).
Н8. Длина клеточной формы обозначена ℓ_cell(O) и отделена от длины объекта со склейками ℓ(O, S) (1.13, Утв. 42).
Н9. λ(β₊) = λ(β₋) = 0 записано явно, с доказательством и по клеткам, и по полному состоянию (O, S).
Н10. Параметр ω (слияние, подъём) убран из α ядра (версия 1.12): совпадение — всегда отказ; ω — надстройка 9.6.
После Н7–Н10 Утверждения 12–19 перепроверены заново (раздел 17 теории): ложных нет, уточнения записаны.

Н6. Надстройки (α*, α°, тонкие объекты, подъём) в ядро не входят; утверждения ядра для них не заявлены.
    В частности, оценка m(O) ≤ ℓ(O) с поворотом α° неверна (поворот меняет оси местами).

Строгие доказательства мест, которые раньше были схемами.

Д1. Лемма к Утв. 14, подсчёт вариантов.
    Пусть сжатие в f раз, непустые блоки B₀ (с клеткой e, на которой достигается a), B₁, …, B_r,
    в блоке B — m_B клеток группы. Рассмотрим множество 𝒱 объектов O', для которых:
    O' \ Z = O \ Z; O' ∩ Z ⊂ G; e ∈ O'; в каждом B_k лежит хотя бы одна клетка O'.
    (1) Для каждого O' ∈ 𝒱 закреплённая сторона та же: anchor_of_subset (Lean).
    (2) Каждый блок G даёт ту же новую клетку, что и в O: shrink_same_of_blocks (Lean) — результаты равны.
    (3) Допустимость: новые клетки сжатия O' — часть новых клеток сжатия O (по (2)), а O' \ G' = O \ G;
        раз П3 выполнено для O, оно выполнено и для O'.
    (4) |𝒱| = 2^(m_{B₀} − 1) · ∏_{k ≥ 1} (2^{m_{B_k}} − 1): выборы по блокам независимы (разные блоки —
        непересекающиеся множества клеток), в B₀ клетка e обязательна, остальные m_{B₀} − 1 — любые;
        в B_k — любое непустое подмножество, их 2^{m} − 1 (все подмножества минус пустое).
    (5) 2^(m₀ − 1) · ∏(2^{m_k} − 1) ≥ 2^(Σ(m − 1)) = 2^d: loss_ge_bits_anchor (Lean).
    Значит, прообразов не меньше 2^d, потеря ≥ d бит. ∎

Д2. Утв. 13, порядок обхода.
    O связен по граням. Построим последовательность c₁, …, c_M всех клеток так, что каждая c_k (k ≥ 2)
    — сосед по грани некоторой c_j, j < k: поиск в ширину по графу соседства по граням (граф конечен
    и связен, поэтому поиск обходит все вершины, а каждая вершина, кроме первой, открывается из уже
    открытой соседней). Шаг k: grow_one (Lean) с клеткой c_j и направлением на c_k даёт
    O_{k−1} ∪ {c_k}; П3 выполнено, так как c_k ∉ O_{k−1}; потеря 0 по stretch_lossless (Lean). ∎

Д3. Утв. 16(а), топологическая часть («K — поверхность с краем, b₂ = 0»).
    (i) Каждая точка K лежит в одном из трёх видов: внутри квадрата; внутри стороны; в вершине.
    Внутри квадрата окрестность — открытый диск. Сторона квадрата принадлежит не более чем одной
    склейке (сторона смотрит ровно на одного соседа), поэтому внутренняя точка стороны лежит в одном
    квадрате (окрестность — полудиск) или в двух, склеенных по этой стороне (диск).
    (ii) Вершина K над точкой p решётки — компонента C графа Γ(p) (vertex_count, Lean: число компонент
    = k − s + [цикл]). Γ(p) — подграф цикла длины 4, его компоненты — пути или весь цикл. Квадраты C
    вокруг p дают секторы по 90°, соседние в C склеены по общему радиусу. Путь из j секторов
    гомеоморфен полудиску (вершина на крае), цикл — диску.
    (iii) Значит, K — компактная 2-поверхность с краем (конечное число квадратов).
    (iv) У каждой компоненты край непуст: возьмём в компоненте клетку с наибольшей первой координатой
    (а при равенстве — с наибольшей второй); её правая сторона не склеена (справа клетки компоненты нет),
    значит лежит в крае.
    (v) Компактная связная поверхность с непустым краем гомотопически эквивалентна графу
    (стягивается на одномерный остов), поэтому H₂ = 0. Это классический факт (например, A. Hatcher,
    «Algebraic Topology», 2002, гл. 2). Тогда χ(K) = b₀ − b₁, откуда b₁ = b₀ − χ(K) = b₀ − |O| + |S| − q,
    где χ(K) = |O| − |S| + q посчитано в euler (Lean). ∎

Д4. Точность переборов в коробке (Н4).
    Теорема stretch_frame (Lean): для растяжения с правильной закреплённой стороной каждая клетка y
    исходного объекта по каждой оси k лежит между двумя клетками результата: x_k ≤ y_k ≤ x'_k.
    Значит, отрезок значений каждой координаты (рамка) при растяжении не сужается. По индукции рамка
    итоговой фигуры содержит рамку каждой промежуточной фигуры. Если итоговая фигура помещается
    в коробку (после сдвига), то каждая промежуточная помещается в ту же коробку тем же сдвигом. ∎
    Следствие: все числа «совпало … из …» в таблицах 10.6 и 10.7 — точные утверждения о ℓ_α для фигур
    из этих коробок с ℓ_α ≤ указанной длины (но не о больших коробках и не о длинных цепочках).

Д5. Утв. 24, сведение (полностью).
    Вход задачи «Нормальный базис»: семейство 𝓕 = {F₁, …, F_m} подмножеств множества U = {u₁, …, u_k}
    и число K. Возьмём первые k простых p₁ < … < p_k (их запись многочленна по k) и высоты
    h_j = ∏_{u_r ∈ F_j} p_r (число цифр ≤ k·log₂ p_k — многочленно). Высоты свободны от квадратов.
    (→) Пусть h_j = m₁·…·m_t — разложение по части набора множителей. Тогда m_a свободны от квадратов
    (sqfree_dvd, Lean) и попарно не имеют общих делителей > 1 (sqfree_parts_disjoint, Lean), поэтому
    множества их простых делителей не пересекаются и в объединении дают множество простых h_j.
    Множители, не делящие ни одну высоту целиком в разложении, можно выбросить. Значит, по набору
    из R множителей строится нормальный базис из ≤ R множеств.
    (←) По нормальному базису {B₁, …, B_R} положим m_b = ∏_{u_r ∈ B_b} p_r; каждое F_j — объединение
    непересекающихся B_b, значит h_j — произведение соответствующих m_b, каждый — не более одного раза.
    Итак, R(H) = наименьший размер нормального базиса, и задача «R(H) ≤ K?» NP-трудна (двоичная запись). ∎

Д6. Утв. 12, нижняя оценка через Lean.
    Брусок со сторонами ≥ 2 по k осям развёрнут вдоль этих k осей (Spreads). По axes_le_length
    любая цепочка ядра (любые α↑, α↓, σ, β, любые зоны), строящая его из одной клетки, имеет длину ≥ k.
    Построение за k растяжений — по одному на ось. ∎
