# Как дополнить «Относительную сетку»

Система открыта: если чего-то не хватает — добавим.

1. **Что добавляете:** определение, действие, правило, формулу (модуль) или утверждение.
2. **Куда:** номер пункта теории (например, 1.7 или Утверждение 16).
3. **Чем подтверждено:** доказательство, проверка программой или источник (для известных формул).
4. **Как прислать:** создайте Issue или Pull request в этом репозитории.

Принятые дополнения входят в новую версию с указанием автора дополнения.
Известные формулы из других разделов математики подключаются с указанием источника (пункт 1.21 теории).
Подробно — раздел 15.4 теории.
